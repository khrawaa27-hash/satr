# سطر

يثبّت ترتيب السطر العربي المخلوط بكلمات إنجليزية قبل النشر على X وGitHub وباقي الصفحات التي اتجاهها من اليسار.

سطر مثل «جربت Claude Code اليوم!» تنقلب كلماته وتذهب علامة التعجب إلى بداية السطر. سطر يغلّف الكلمة الإنجليزية بعازل اتجاه، ويثبّت الفقرة لليمين، من غير عكس الحروف ومن غير علامة القلب الإجباري.

## التشغيل

```bash
npm install
npm test
npm start
```

ثم افتح `http://localhost:4173`.

الصق المنشور، قارن الصندوقين، ثم انسخ النص الجاهز. العلامات المخفية تثبت ترتيب الكلمات على X وGitHub ومنصات التواصل وكافة المواقع الأخرى. محاذاة الفقرة إلى اليمين تبقى قرار الموقع نفسه.

## إضافة كروم

1. شغّل `npm run build`.
2. افتح `chrome://extensions`.
3. فعّل وضع المطوّر.
4. اختر «Load unpacked» ثم مجلد `extension`.

الإضافة تضبط اتجاه الفقرات العربية إلى اليمين داخل أي صفحة، وتترك كتل الكود كما هي. من النافذة المنبثقة يمكن إيقافها أو لصق نص قبل النشر.

## تطبيق الهاتف

من متصفح الهاتف افتح الصفحة واختر «إضافة إلى الشاشة الرئيسية». بعد التثبيت، مشاركة أي نص إلى سطر تفتحه جاهزاً للنسخ.
